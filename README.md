# 🔊 VOICEVOX TTS Chrome拡張機能

選択したテキストをVOICEVOXで読み上げるChrome拡張機能です。

---

## 📋 必要なもの

- **VOICEVOX** がローカルにインストールされ、起動していること  
  ダウンロード: https://voicevox.hiroshiba.jp/  
  デフォルトAPIポート: `http://127.0.0.1:50021`

---

## 🚀 インストール方法

1. このフォルダをダウンロード（またはクローン）
2. `icons/` フォルダに以下のアイコン画像を用意する
   - `icon16.png`（16×16px）
   - `icon48.png`（48×48px）
   - `icon128.png`（128×128px）
3. Chromeで `chrome://extensions/` を開く
4. 右上の「デベロッパーモード」をオンにする
5. 「パッケージ化されていない拡張機能を読み込む」をクリック
6. このフォルダを選択する

---

## 📖 使い方

### 右クリックメニューから読み上げ
1. Webページ上のテキストを**マウスでドラッグして選択**
2. **右クリック**してコンテキストメニューを開く
3. **「🔊 VOICEVOXで読み上げる」** をクリック
4. ページ右下にトースト通知が表示され、読み上げが開始されます

### キーボードショートカットから読み上げ
1. Webページ上のテキストを**マウスでドラッグして選択**
2. キーボードの **`Alt + V`** を押す（デフォルト設定）
3. ページ右下にトースト通知が表示され、読み上げが開始されます

> **💡 ショートカットキーの変更方法**  
> Chromeのアドレスバーに `chrome://extensions/shortcuts` と入力して開くことで、「VOICEVOX テキスト読み上げ」のショートカットをお好みのキー（例: `Alt + S` など）に変更できます。

### ポップアップ設定（拡張アイコンをクリック）
- **話者キャラクター**: 読み上げキャラを選択
- **話速**: 0.5〜2.0倍速
- **ピッチ**: 声の高さを調整
- **音量**: 音量を調整
- **テスト読み上げ**: 設定確認用

## 📁 ファイル構成

```
voicevox-tts-extension/
├── manifest.json   # 拡張機能の設定
├── background.js   # サービスワーカー（API通信・コンテキストメニューの制御）
├── content.js      # コンテンツスクリプト（WEBページ内へのトースト表示）
├── offscreen.html  # オフスクリーンドキュメント（音声再生用UIなしHTML）
├── offscreen.js    # 音声再生用ロジック（音声キュー管理・再生）
├── popup.html      # ポップアップUI（パラメーター調整、テスト読み上げ）
├── popup.js        # ポップアップのロジック
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

### 💡 音声再生の仕組み（Offscreen Document）
Chrome 拡張機能 Manifest V3 の仕様により、バックグラウンド（Service Worker）で音声を直接再生することができません。  
そのため、本拡張機能では音声再生を目的とした目に見えない裏画面（`offscreen.html` / `offscreen.js`）を動的に立ち上げ、そこで `Audio` オブジェクトを使って音声を再生しています。

---

## ⚠️ 注意事項

- VOICEVOXは必ず**起動した状態**で使用してください
- デフォルトのAPIポートは `50021` です。変更している場合は `background.js` と `popup.js` の `VOICEVOX_URL` を修正してください
- テキストは `。！？.!?` で文ごとに分割して順次合成・再生するため、最初の1文が合成され次第すぐ再生が始まります

---

## 🛠️ トラブルシューティング（接続できない場合）

VOICEVOXを起動しているにもかかわらず、ポップアップ上で「未接続」と表示され、再接続をクリックしても接続できない場合は、**Chrome拡張機能のアクセス権限**が制限されている可能性があります。

### 対処方法
1. Chromeの拡張機能管理画面（`chrome://extensions/`）を開きます。
2. 「VOICEVOX テキスト読み上げ」の **「詳細」** ボタンをクリックします。
3. **「サイトへのアクセス」** という設定項目を確認します。
4. 設定が「クリックされた場合のみ」になっている場合は、**「すべてのサイト」** に変更してください。
5. 拡張機能ポップアップを開き、ステータスバー（または `🔄 再接続`）をクリックして接続されることを確認します。

### 🔒 セキュリティについて（安全性の説明）
「すべてのサイト」にアクセス許可を与える際、Chromeから警告が表示されますが、この拡張機能は**安全**です。

- **通信はローカルPC内のみ**: 拡張機能がアクセスする先は、インターネット上のサーバーではなく、ご自身のパソコン内で動いているVOICEVOX（`http://127.0.0.1:50021`）のみです。外部サーバーへデータを送信する仕組みはありません。
- **機能実現のため**: 任意のウェブページで「テキストを選択して右クリックで読み上げる」という機能を実現するために、この「すべてのサイト」権限が必要となります。
